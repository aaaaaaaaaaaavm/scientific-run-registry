# Provenance and limits

This package generalises run freshness and evidence-registration patterns used in
[engineering-evidence-toolkit](https://github.com/aaaaaaaaaaaavm/engineering-evidence-toolkit),
[VOLLEY](https://github.com/aaaaaaaaaaaavm/VOLLEY), BOLLEY, and GatewayCX.

The registry proves internal content identity and parent presence. It does not independently
validate a scientific method, establish authorship, or make an external timestamp claim.
